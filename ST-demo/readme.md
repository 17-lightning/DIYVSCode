1. 更详细的解析子函数，if/for/while/switch 现在将被更详细的解析，并产生对应的`finish`标记
    被do while埋伏了，怎么会有这么特殊的一个语法现在我要怎么解析？
    `if`-`then`-`else`-`0ut`
    `while`-`then`-`0ut`
    `do`-`while`-`0ut`
    `for`-`then`-`0ut`
    `switch`-`case 0`-`default`-`0ut`
    当识别到 `if` `while` `for` `switch` 时，后面总是跟随着一个 `()` 的判断式，我们认为这是`assert`的开始，并且记录下此时的`in_bra`
    当对应的`in_bra`被弹出时，`assert`结束，此时会记录一个`then`到子函数列表中，并且标记`block`
    `block`的内容可以是`{}`，也可以是`;`
    当`block`被弹出时，若当前为`if`块，需向后寻找有无`else`块，若有，对`else`再次进入`block`状态
    `else`的`block`可以是`{}`，可以是`;`，还可以是`if`
    当`block`被弹出时，若当前为`do`块，则标记`do_while`，下一个`while`将被直接录入为子函数，而不是像正常`while`一样启发`assert`和`block`
